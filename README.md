# Bootstrap e JavaScript — Card Interativo

Projeto prático desenvolvido com **HTML5, Bootstrap 5 e JavaScript puro (Vanilla JS)**, demonstrando a integração entre estilos e componentes do Bootstrap e a manipulação dinâmica de elementos HTML com JavaScript.

## Funcionalidades

- Card responsivo utilizando o componente Card do Bootstrap 5.
- Imagem, título e descrição.
- Botão interativo com evento `addEventListener()`.
- Alteração dinâmica do texto e das cores do card.
- Alternância entre dois estados utilizando JavaScript.

## Tecnologias utilizadas

- HTML5
- Bootstrap 5.3.3 (CSS e JavaScript via CDN)
- JavaScript (Vanilla JS)

## Conceitos praticados

- Estruturação de páginas HTML.
- Utilização de classes e componentes do Bootstrap.
- Manipulação do DOM.
- Seleção de elementos com `getElementById()`.
- Eventos com `addEventListener()`.
- Manipulação de classes CSS com `classList`.
- Alteração de conteúdo com `textContent`.

## Execução

1. Clone ou baixe este repositório.
2. Abra o arquivo `index.html` no navegador.
3. Clique no botão **Ver conteúdo** para visualizar as alterações no card.

**Observação:** o projeto utiliza Bootstrap via CDN, sendo necessária conexão com a internet para carregar os arquivos da biblioteca.
